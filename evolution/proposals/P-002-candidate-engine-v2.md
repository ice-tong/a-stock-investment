# P-002 候选引擎 v2：从“技术面多路召回”到“状态感知的多风格候选 + 组合槽位”（影子实验）

- 类型：挑战者实验（影子候选池，不改 main 下单）＋流程修复（候选呈现、触发条件、漏斗记录）
- 状态：**待批准**（批准、否决只由用户在对话中决定；本文件由首席研究员在交互会话提出，供用户与进化官审阅）
- 提出日期：2026-10-25；提出时策略版本：strategy-v1.0
- 关联：P-001（新仓仓位分档，仍未决）；观察项 O-003（研究任务时间窗）

## 问题与证据

### 事实：候选池不是“太小”，而是“目标函数单一 + 信息密度低 + 与持有期/退出规则错配”

1. **漏斗规模**：全市场 5576 只 → 基础过滤 4391 → 流动性预过滤 2500 → 有效特征 2473 → 合规 2080 → 多路召回 114 只（`data/pool/2026-10-23.md`）。114 只相当于合规股的 5.5%，不是数量不足。
2. **风格同质**：6 条通道里 momentum / trend / breakout / sector 四条是趋势-动量家族，pullback 也要求中期趋势向上；pool 中 **96% 的股票收盘价在 MA120 上方**，而合规股票池只有 22.6%。pool 的 20 日收益中位数 +7.4%，合规池为 −6.2%，约等于只取全市场 20 日动量的前 10%。
3. **“多通道共振”是动量代理**：n_channels 与 ret_20 的 Spearman 相关 0.52；3 通道股的 20 日收益中位数 **+100.9%**、PE 中位数 **198.6**；18 只多通道股中 7 只 20 日涨幅 >30%、6 只 60 日波动 >60%、5 只 PE>100 或为负。当前研究 prompt 让 Agent“多通道共振优先”，等于优先研究最极端的动量股。回测中 3+ 通道股 20 日超额 −2.7%、60 日 −8.3%、60 日胜率 28%。
3b. **通道不是正交的**：日度 20 日超额相关——候选池 vs momentum 0.94、pullback 0.94、trend 0.90、sector 0.84；pool 内 s_mom 前 15 与 momentum 0.96；只有 lowvol 与候选池负相关（−0.17）。再加动量类通道只会放大同一个 beta。
3c. **替代通道**：squeeze（缩量整理）过滤域 IC 5/20 日 +0.036/+0.050（t=2.8/3.9），月度 5/6、非重叠批次 5/6 为正，与候选池相关 0.60，是唯一有增量信息的替代通道；high52w 与 breakout 相关 0.62、IC≈0；ind_mom IC 全负（−0.061/−0.077/−0.154）；trend 明确为负（60 日 −8.0%、IC −0.21）。
4. **与 1–6 个月持有期错配**：2026-04-01～09-18 的离线回测（T+1 收盘买入，超额相对当日合规池中位数，`evolution/analysis/2026-10-25_pool_channel_backtest.md`）显示：
   - 60 日：trend −8.0%（中位 −15.0%，胜率 28%，IC −0.21）、pullback −5.5%、sector −2.6%、momentum −2.0%；而 lowvol（低波，替代无历史 PE 的 defensive）**+10.8%**（中位 +11.6%，胜率 87%，IC 0.28）——但 lowvol 的 2,950 个股票-日里 21% 是金融、9% 电力、4% 交运，本质是“银行+公用事业+低 beta”的风格暴露；60 日结果被 2026-08～10 单边下跌主导，不能当横截面选股 alpha。
   - 20 日：momentum 平均 +3.1% 但中位 −1.2%、胜率 47%；lowvol +3.2%、中位 +3.2%、胜率 65%；breakout +4.4% 但中位仅 +0.4%。
   - 3 通道共振股：20 日超额 −2.7%、60 日 −8.3%、60 日胜率 28%；n_channels 与 20 日超额相关 −0.027。
   - 候选池全体：20 日 +2.7%（中位 +0.4%）、60 日 −0.3%（中位 −2.4%）；池内 s_mom 前 15 的 60 日超额 −2.2%、中位 −9.8%、胜率 38%。
5. **风控/退出规则与候选波动错配**：pool 60 日波动中位数 37.2%，按 −8% 固定止损、20 日持有估算，漂移率为 0 时触及止损的概率平均约 **43%**；31/114 只 60 日波动 >60%。用“高波动动量股 + −8% 止损 + 20 日时间止损”的组合，候选层先把胜率结构压低了。
6. **信息密度低、注意力组织反了**：pool 表只有价量 + PE/流通市值；PE/行业仅覆盖合规池的 **61%**（1268/2080），pool 内 39/114 缺行业/PE；114 行长表按“多通道 → momentum → trend → pullback → defensive…”排序，防守期（当前 regime=defense）最重要的 defensive 排在第 4 段之后。外部证据（`docs/research/2026-10-25_candidate_selection_review.md`）表明长上下文会显著衰减 LLM 判断质量，30–50 张结构化卡片优于 100+ 行长表。
7. **无跨日记忆、无触发、无反馈**：观察名单 10-23 为空；首晚研究没有留下 `journal/research/2026-10-25.md` shortlist 记录；没有对 pool/shortlist 做前向收益跟踪。候选层无法知道“哪条通道真的有用”“为什么放弃”。
8. **首份草稿的示意**：10-27 草稿只有伊利股份 3%，理由为“三季报前底仓，中石油/长电等财报后再议”。这是“候选池给的是热门动量，研究结论却是等财报/等回调”的典型错配（n=1，只作示意，不作统计证据）。

### 外部证据（摘要，详见 docs/research 综述）

- A 股 2015–2025 全样本：3 月动量 IC −0.032、ICIR −0.244（t=−2.66），动量方向与“追涨”相反；反转、低波/低换手/低估值/高股息证据更硬（国信稳健池年化 13.81%、超额 7.31%，行业权重上限 15%/个股 3%）。
- PEAD（业绩后漂移）5 日窗口 IC 10.96%，但必须按个股自身披露日动态跟踪，统一横截面会失效——天然适配“事件日历 + 观察名单 + 触发条件”，而不是每晚全市场重扫。
- 北向资金日频净买入自 2024-08-19 起不再披露，不能当候选通道；LLM 的收益类回测数字不可采信，只采信其上下文/流程经验。
- 多阶段漏斗 + 类别平衡、分层记忆/反思、候选卡片（30–50 张）是较可移植的架构经验。

### 证据边界（必须先说清）

- 回测只覆盖 2026-04～09 一个窗口，60 日样本相互重叠、t 值高估显著性；行业标签/PE 用当前值（轻微前视）；未计交易成本；存在幸存者偏差（只含 2026-10-23 仍存续的 2473 只）。
- lowvol 的强超额可能是该窗口的风格/低 beta 效应，不能直接当作长期参数；只能作为“方向性先验”，必须影子验证；60 日只有约 2 个非重叠批次，t 值不可信。
- 当前 main 尚无已平仓交易（0 笔），按进化纪律，**不能直接改 main 的选股参数/提示词**；因此本提案只做影子候选池 + 流程修复，不动 main 下单。

## 改动（精确到文件与字段）

### 阶段 0：流程修复（候选呈现与记录；不改变主策略选股逻辑）

1. `sim/pool.py`
   - `features()` 增加确定性字段：`stop_prob = 2Φ(−0.08 / (vol_60·√(20/250)))`、`one_lot_value = close*100`、`dist_ma20`、`dist_ma60`、`dist_high60`。
   - `assemble()` 不再按 `n_channels` 优先排序；改为按“当前 regime 的风格配额 + 可行动性（距触发距离）+ 风险适配（stop_prob）”排序，`n_channels` 只作展示字段。
   - `to_markdown()` 改为：
     `## 今日状态`（regime、建议风格配额、组合缺口）→ `## 今日可行动`（触发已近/已满足）→ `## 等触发`（按风格分组，附数值触发位）→ `## 防守储备` → `## 持仓复核` → `## 观察名单触发` → 完整卡片表。
   - 卡片字段改为固定 12–15 项：代码/名称/风格/行业/收盘/20-60-120 日收益/60 日波动/回撤/PE/PB/流通市值/日均成交/行业排名/stop_prob/一手金额/持续性/触发位/一句话风险。
   - `run()` 读取最近 10 个交易日的 `data/pool/<日期>.csv`，计算 `persist_days`（连续/累计进池天数）；无历史则记 1。
   - 观察名单：读 `data/watchlist.json` 的 `trigger` 字段并做数值化评估（若 trigger 是结构化字段）；不能解析的保留原文、标记“需人工复核”。
2. `docs/automation/prompts/research.md`
   - 第 6 步：仍用 `python -m sim pool`，但改为读“今日可行动/等触发/防守储备”分诊结果。
   - 第 7 步：删除“多通道共振优先”，改为“先按 regime 与组合缺口分配研究配额（防守：低波/回调优先；进攻：突破/行业龙头优先），再在配额内选 6–8 只”；要求 shortlist 每只写明“入场触发 + 证伪条件”；被放弃的前 10 只写一句原因，写入 `journal/research/<日期>.md`。
   - 第 8 步：深度研究必须产出“现在买/等触发/放弃”三选一，并给出可被代码检查的触发位；不满足触发位的写入观察名单，不强行下单。
   - 第 8b 步：观察名单 `trigger` 改为结构化（如 `{"type":"pullback_to_ma60","level":10.56}`），由 pool 每晚评估；`review_by` 到期自动清理。
   - 第 9 步：组合决策先看“槽位”（行业上限 35%、最多 6 只、当前持仓行业暴露），再在槽位内排序，禁止 6 只同风格/同行业。
3. 记录：新增 `journal/research/<日期>.md` 的固定段（shortlist/放弃原因/深度研究结论/最终订单映射），供后续归因；不改 `accounts/`、`orders/`、`config/risk.yaml`。

### 阶段 1：影子候选引擎 v2（挑战者实验，不改 main 下单）

1. 新增 `sim/pool_v2.py`（或 `pool.py --engine v2`），输入复用当天 `data/cache/pool/<日期>_features.csv`，不额外取数：
   - 五条正交轴（每轴独立排序，行业中性版本；**trend / ind_mom 下架**，momentum 只保留“等回调”观察位、不直接买）：
     - `lowvol`：收盘>MA120，60 日波动最低；PE 0–30（有 PE 时）；（防守核心，但按“风格暴露”单独限额，≤40%）
     - `squeeze`：5 日/20 日成交额比 <0.8 且收盘>MA60，越缩量越前；（回测里唯一有增量信息的替代通道）
     - `pullback`：中期趋势向上，回撤 8–20%，近 5 日下跌，优先靠近 MA60/MA120 支撑、低波动；
     - `breakout`：接近 60 日新高 + 放量，但剔除 20 日涨幅 >30% 或 60 日波动 >50% 的极端；
     - `reversal`：长期趋势向上、20 日超跌、行业内排名，避免接飞刀极端。
   - regime 配额（合计 48–60 只）：防守 lowvol 35% / pullback 25% / squeeze 20% / breakout 10% / reversal 10%；中性 lowvol 20 / squeeze 20 / pullback 25 / breakout 20 / reversal 15；进攻 breakout 30 / squeeze 20 / pullback 20 / lowvol 15 / reversal 15。
   - 行业约束：每行业 ≤3 只、覆盖 ≥8 个行业；行业中性排序后再全局截断。
   - 风险适配：`stop_prob > 0.45` 或 `one_lot_value > 5%×权益` 的标的降权/剔除；波动 >60% 的标的只进“观察”不进“可行动”。
   - 输出 `data/pool_v2/<日期>.md` 与 `.csv`（与 v1 并列，不覆盖 `data/pool/`）。
2. `research.md` 增加“影子 shortlist”：从 v2 板选 5 只（不研究、不下单），写入 `journal/research/<日期>.md`，与 v1 shortlist 并列；用于 20–30 个交易日后比较前向收益。
3. 可选：`sim attrib`/`tools/build_dashboard.py` 增加 `pool_v1 vs pool_v2` 的影子记分板（5/20/60 日超额、胜率、stop_prob），不改 main 账户。

## 预期效果与验证方式

- 影子池结构目标：40–60 只、≥8 个行业、每行业 ≤3 只、防守期 momentum/trend 占比 ≤25%、pool 中位 60 日波动 ≤40%、平均 stop_prob ≤0.35。
- 20–30 个交易日后看：
  1. v2 影子池的 20 日/60 日横截面超额是否 ≥ v1 池（以合格池中位数为基准）；
  2. v2 影子 shortlist 的 20 日超额是否 ≥ v1 shortlist；
  3. Agent 的“深度研究→订单”转化率是否提升（当前首晚 1 份草稿/3% 仓位）；
  4. 研究任务是否仍在 20:00 前完成（runlog 时间戳）。
- 成功判据（先写死）：v2 影子池 20 日超额比 v1 高 ≥1 个百分点，且 60 日不劣于 v1；同时 stop_prob 不高于 v1；研究时长不超 20:00。满足才向用户提案切换 main。
- 失败/回滚：若 20 个交易日内 v2 影子 20 日超额持续低于 v1，或研究任务晚于 20:00，停止影子实验；删除 `data/pool_v2/` 与 prompt 影子步骤即可回到 v1，main 从未被改动。

## 反方论证

- 回测窗口单一、重叠样本、生存偏差、未计成本；lowvol 的强超额本质是“银行+公用事业+低 beta”的风格暴露，且 60 日结果被 2026-08～10 单边下跌主导（60 日只有约 2 个非重叠批次）；用 2026-04～09 的结果设计 2026-10 之后的策略，存在过拟合风险。
- 4 条趋势/动量通道的日度超额相关 0.84–0.94，说明“加通道”没有分散价值；v2 若只是把通道名换一遍，不会变好。
- regime 配额（40/30/15/10/5）是主观先验，没有校准；参数一多，容易把“候选层”做成另一个黑箱。
- 增加候选池复杂度会拉长 19:00–20:00 的时间窗（O-003 已经提示）；影子 shortlist 可能挤占深度研究时间。
- 候选层改造的收益上限受 P-001 约束：防守期个股上限 20%、研究 prompt 单只 ≤5%，即使选股超额 +3%/月，账户层面影响也有限；P-001 未决前，不要高估本提案的作用。
- LLM 可能继续按“熟悉的名字/极端涨幅”选股，不遵守新配额；需要用记录和归因验证，而不是假设它会遵守。

## 失效判据与回滚

- 失效判据：影子 20 日超额 ≤ v1 连续 20 个交易日；或 v2 池的行业/风格分布仍被单一风格占据（>50%）；或研究任务晚于 20:00 两次以上。
- 回滚：阶段 0 只改 `sim/pool.py` 输出与 prompt，git revert 即可；阶段 1 是只读影子，删除 `data/pool_v2/` 和 prompt 中的影子步骤即可；`config/risk.yaml`、`accounts/`、`orders/` 全程不动。
