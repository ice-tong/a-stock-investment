## 为什么单独放一个目录
实验只能前向验证（LLM 训练数据含历史行情，回测会虚高）。2026-11-01 用户要求看"如果当时的尾盘任务在，会选什么"，于是用回放数据让全新的 Agent 会话按真实提示词做了一次决策。这类结果只能用来检查流程、观察决策风格，不能当证据，所以与正式记录隔离。
