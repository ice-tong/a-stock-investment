## 接手规则
1. 开工前运行 `git status` 和 `git log --oneline -5`，了解最近谁做了什么；完成后提交，提交信息写明工具名，如 `[qoder] ...`。
2. **定时任务只能在一个工具里配置**（`python -m sim execute` / `evening`），多个工具同时跑会互相干扰。当前由：**Qoder 内建 cron 承担**（2026-10-24 创建，任务 ID 与移交方式见 `docs/tools/qoder.md`）。
3. 不要修改 `accounts/`、`orders/` 已冻结文件和 `config/risk.yaml`；试验用 `SIM_HOME` 指向临时目录。
4. 子代理提示词源文件在 `prompts/`；不支持子代理的工具，可以直接读取 `prompts/agents/<名称>.md` 按角色执行。
5. Python 环境：`.venv/bin/python`；缺失时运行 `uv venv .venv --python 3.11 && uv pip install --python .venv/bin/python akshare tabulate pyyaml pytest`。
6. 做完一段工作，更新本文件的"当前状态"和下方日志。
