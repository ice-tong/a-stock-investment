# 选股策略探索·第三轮：组合构造（预注册，2026-11-01，写于看结果之前）

> 前两轮：[第一轮](选股策略_预注册_2026-11-01.md)、[第二轮](选股策略_预注册_第二轮_2026-11-01.md)。结论：小市值是唯一有一致超额迹象的方向（16 次随机切分超额平均 +4.8pp），但「最小 20 只」组合噪声大（同规则换一半股票年化差 10pp）、回撤深（−25%~−49%）、换手高（约 1.1/月）。
> 本轮问题：**不换因子，只改组合构造（持股数、分层、缓冲换仓），能否得到更稳、回撤更浅、扣费后仍跑赢基准的小市值方案？**

## 1. 沿用

股票池、资格、交易执行（月末信号、次日开盘、买不进留现金、跌停顺延）、成本 0.35%/来回、ST 口径（当前名称）、排序因子（20 日平均流通市值，升序）不变。

## 2. 规则（5 条）

| # | 构造 | 动机 |
|---|---|---|
| K1 | 最小 50 只，等权 | 稀释单票噪声 |
| K2 | 最小 100 只，等权 | 进一步稀释 |
| K3 | 可投资格内市值最小 20%（全部持有，等权） | 类「微盘指数」，持股数随资格池变化 |
| K4 | 50 只 + 缓冲：已持有且仍在最小 100 名内的继续持有，空位按排名补足 | 降换手 |
| K5 | 100 只 + 缓冲：已持有且仍在最小 200 名内的继续持有，空位补足 | 降换手 |

## 3. 检验：多次随机切分（替代单次留出集）

- 20 次切分：`md5(f"r3-{k}:" + code)` 取偶数一半，k = 0…19。每次同时跑等权基准（不扣费）。
- 另报全市场（不切分）结果与三段年化。
- **门槛（全部满足才存档）**：
  1. 20 次切分扣费 CAGR 的**中位数 ≥ 5%**；
  2. 超额（相对等权基准）**为正的切分 ≥ 16/20**，且**平均超额 ≥ 2pp**；
  3. 全市场三段（2020–22、2023–24、2025–26）年化均 > 0；
  4. 全市场最大回撤（月末采样）≤ 40%，否则标红。
- **≥20% 档**：全市场 CAGR ≥ 20%，20 次切分中位数 ≥ 15%，且剔除 2024-01~02、2024-09-24~10-08 后仍 ≥ 15%。

## 4. 诚实声明

- 这里没有真正的样本外：全部股票、全部时段都在前两轮被小市值规则看过。多次切分只检验「对股票构成的稳健性」，不检验时间外推。**存档 ≠ 可以实盘**，必须再经前向纸面验证。
- 退市幸存者偏差未解决，对小市值偏乐观。

## 5. 不做的事

不调排序因子、不加财务过滤、不加择时；看完结果不改 N、分位、缓冲宽度。

## 6. 结果登记（运行后追加，不改上文）

- 报告：[reports/20261101_选股策略_第三轮.md](../../reports/20261101_选股策略_第三轮.md)。
- 通过：**K2（最小 100 只）→ S-002**、**K3（最小 20% 全持）→ S-003**：20/20 切分超额为正，平均 +2.4 / +2.1pp，全市场 12.2% / 12.7%，三段为正，回撤 −30.1% / −31.2%。
- 否决：K1（15/20、+1.9pp）、K4（2/20）、K5（14/20、+0.9pp）。
