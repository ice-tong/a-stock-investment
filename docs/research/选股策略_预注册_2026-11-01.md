# 选股策略探索：预注册（2026-11-01，写于看结果之前）

> 目标：找一个**买卖条件朴素、主要靠选股**的方案，扣费后年化 ≥5% 即存档，长期目标 ≥20%。
> 方法纪律沿用 [隔夜策略_理论边界与探索方针.md](隔夜策略_理论边界与探索方针.md) §5：先写假设和门槛，再看结果；每轮 ≤5 条规则；失败也记录。

## 1. 数据与股票池

- 数据：`tools/select_data.py`，新浪前复权日线 2020-01 ~ 2026-10，**当前在市的全部沪深 A 股**（不含北交所）。
- 已知偏差：拿不到已退市股票 → 退市幸存者偏差，**对小市值/低价/高波动方向偏乐观**；ST 状态只有当前名称，无法时点还原。
- **样本切分**：按代码哈希把股票随机分成 A（发现集）、B（留出集）两半。规则只在 A 上看结果；B 只在规则定稿后跑一次。
- **每期可投资格**（时点重算，只用当时已知数据）：
  - 上市满 250 个交易日（以本数据的观测数计；**首个观测就在 2020-01-02 的视为老股**，否则 2020 全年都会被排除——此修订写于运行任何回测之前）；
  - 近 20 日日均成交额 ≥ 5000 万元；
  - 近 20 日成交均价（成交额/成交量，未复权）≥ 3 元；
  - 当前名称不含 ST/退。

## 2. 交易规则（所有假设共用，不调）

- **调仓**：每月最后一个交易日收盘后出信号，**下一交易日开盘**等权买入前 N 只，持有到下次调仓日的次一交易日开盘卖出。
- **N = 20**（另报 N=10/50 仅作敏感性，不作为选择依据）。
- **买不进**：执行日开盘价 ≥ 前收 ×(1+涨停幅度−0.5%) 视为一字/顶板，跳过，资金留现金；**卖不出**（开盘跌停）顺延到下一个交易日开盘。
- **成本**：佣金 0.025%×2、印花税 0.05%（卖）、过户费 0.001%×2、滑点 0.10%×2 ≈ **0.35%/来回**，按实际换手扣。
- 无止损、无择时、无仓位管理。

## 3. 假设（第一轮，5 条）

| # | 规则（取排序最前 20 只） | 机制（钱从谁口袋来） |
|---|---|---|
| H1 低波动 | 近 60 日日收益标准差最低 | 散户彩票偏好，为高波动股付溢价；低波动股被系统性低估 |
| H2 低换手 | 近 20 日平均换手率最低 | 投机/注意力溢价：高换手股被追捧而高估（A 股换手率异象） |
| H3 短期反转 | 近 20 日收益最低 | 散户过度反应与流动性冲击，短期回吐/修复 |
| H4 小市值 | 流通市值（成交额/换手率）最小 | 小盘溢价、壳价值、机构回避；2024 后受退市新规冲击，风险已知 |
| H5 低波+低换手 | H1、H2 截面排名等权相加，取最低 | H1 与 H2 同属「反投机」，合成降低单因子噪声 |

## 4. 门槛（全部满足才存档）

1. **A 集**：扣费 CAGR ≥ 5%；
2. **分段稳定**：2020–22、2023–24、2025–26 三段年化收益均 > 0；
3. **相对基准**：相对 A 集「可投资格内等权全体」的超额，在三段中至少两段为正（否则只是吃 beta）；
4. **B 集（留出）**：同一规则扣费 CAGR ≥ 5%，且与 A 集同号；
5. 报告最大回撤、年化波动、月胜率、平均换手；回撤 >40% 的方案存档时标红。

达到 ≥20% CAGR 的方案另需：B 集也 ≥15%，且剔除 2024-01~02 小盘踩踏与 2024-09-24~10-08 行情后仍满足门槛 1–2。

## 5. 不做的事

- 不在看到结果后调窗口长度、N、过滤阈值；要改就开第二轮、重新预注册。
- 不组合超过 2 个因子、不加择时。
