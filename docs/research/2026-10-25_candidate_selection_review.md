# LLM Agent 选 A 股：候选生成与选择策略的外部证据综述

日期：2026-10-25　｜　性质：外部研究综述（不含代码/配置改动，不构成投资建议）

## 摘要

当前漏斗（六路技术面召回 → 约 114 只候选 → LLM 点评 6–8 只 → 深研 3–5 只）的问题不在"LLM 不够聪明"，而在**第一层的输入分布太窄**：六条通道中五条是趋势/动量方向，等于把"全市场"先压成了"上涨趋势子集"，LLM 只能在偏置过的池子里做减法。更优解不是换更大的模型，而是换**候选生成的目标函数**：先做行业中性 + 多风格打分，再把候选压到 30–50 张结构化卡片，最后让 LLM 做排序与淘汰。

**适用前提**：A 股、10 万元、2–6 只、持有 1–6 个月、T+1 14:45 执行、每晚 1 小时内研究、单只 −8% 止损 / 20 日时间止损、排除科创/北交/ST、日均成交额 ≥1 亿。所有结论都要服从这个约束——它意味着**换手成本极高**（双边约 0.46%/次，见下文），任何"月度调仓"结论都不能直接照搬。

## 一、A 股可验证的因子与异象

| 异象 | 方向与适用期限 | 效应量 | 证据等级 |
|---|---|---|---|
| 短中期**反转** | 月频、3 月回看最强，随回看期拉长衰减 | 3 月动量 IC −0.032、ICIR −0.244、t=−2.66；五分位多空（低减高）年化 −6.8%；12 月回看衰减到 ≈0 | 有证据（单一平台全样本 2015–2025） |
| 残差动量 | 剔除市场/行业 β 后方向转正 | ICIR 由 −0.24 转为 **+0.15**（t=1.47，不显著） | 有证据但弱 |
| 低波 / 低换手 / 低估值 / 高股息 | 长期（1 年以上）有效，月频调仓 | 稳健股票池年化 13.81%，超中证 800 全收益 7.31%；增强因子 RankIC 7.83%、年化 ICIR 1.64；精选组合 2012 年来年化 26.53% | 有证据（券商回测） |
| PEAD / 业绩后价格跳跃 | 公告后 5 日最强，10 日衰减；**必须按个股自身披露日动态跟踪** | 5 日窗口 IC **10.96%**；改成统一横截面后有效性明显衰减甚至转负 | 有证据（华泰，单年样本） |
| 行业动量 | 月度，与量价因子低相关 | 月度 IC 3.03%、ICIR 0.22；但长期不稳定，2026 上半年强势、7 月单月中期动量回撤 33.88%、短期反转 +34.80% | 有证据 |
| 小市值 / 微盘 | 拥挤交易，尾部风险极大 | 2024 年 1–2 月量化策略创下"史上最大回撤"，微盘/小市值拥挤交易集中踩踏 | 有证据（事件性） |
| 北向 / 主力资金 | 日频已不可复现 | 2024-08-19 起停止披露每日北向净买入，只留日成交总额、前十大活跃股与**季度**持仓 | 有证据（制度事实） |
| 拥挤度 | 作为行业动量的辅助否决项 | 无稳定阈值；申万把"行业动量+拥挤度"归为与选股正交的增量信息 | 合理推断 |

**关键判断**：动量类证据的方向与当前用法**相反**（3 月动量 IC 为负，做多高动量组年化反而最低），拥挤度则几乎没有可复现的阈值；而当前六条通道恰好集中在这两端。反转、低波低换手、PEAD 才是方向明确、且与"持有 1–6 个月"更匹配的方向。来源：[BigQuant 动量实证](https://bigquant.com/wiki/doc/vmpoW4sE1e)、[国信稳健型选股](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/11/rptid/786013348601/index.phtml)、[华泰 PEAD](https://m.163.com/dy/article/KRGO6KRB05568W0A.html?spss=adap_pc)、[申万行业动量分域](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/lastest/rptid/825501120248/index.phtml)、[行业动量反转复盘](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/strategy/rptid/839360483335/index.phtml)、[微盘回撤](https://www.cnstock.com/commonDetail/19439)、[北向披露调整](http://stock.caijing.com.cn/20240819/5031228.shtml)。

## 二、LLM / Agent 架构：哪些设计被证明有用

- **多阶段漏斗 + 类别平衡过滤，优于端到端生成**。LLM 先生成因子候选、再由多模态 Agent 按"市场状态 + 预测力 + 类别平衡"过滤、最后动态配权，在 2023 年上证 50 上累计收益 53.17%（[2409.06289](https://arxiv.org/abs/2409.06289)）。"类别平衡"这一条可直接搬到"通道/行业配额"。
- **分层记忆与反思降低信息丢弃**。FinMem 用浅/中/深三层记忆 + top-K 检索 + 即时/延时反思，在真实股票数据上跑赢多种算法代理（[FinMem](https://arxiv.org/abs/2311.13743)）；FinAgent 加工具调用与双层反思，在 6 个数据集、9 个基线上平均利润提升超 36%（[FinAgent](https://arxiv.org/abs/2402.18485)）。二者共同点：**不让模型一次读完所有原始数据**。
- **多智能体辩论能降幻觉**：多轮辩论显著提升事实正确性、减少谬误（[Du et al.](https://arxiv.org/abs/2305.14325)）；TradingAgents 把基本面/情绪/技术分析师 + 多空研究员 + 风控团队串成流程（[TradingAgents](https://arxiv.org/abs/2412.20138)）。但注意其收益结论有第三方复现争议（见第四节）。
- **人机交互式因子挖掘**：Alpha-GPT 让 LLM 把研究员的自然语言想法翻译成可执行 alpha，价值在"提高研究吞吐"而非"自动赚钱"（[Alpha-GPT](https://arxiv.org/abs/2308.00016)）。
- **上下文工程是硬约束**：18 个模型上，输入越长性能越不稳，干扰项影响随长度放大；只给"相关片段"（约 300 token）显著优于给完整 113k token 上下文（[Context Rot](https://www.trychroma.com/research/context-rot)）；关键信息放在长文本中部会被明显忽略（[Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/)）。

## 三、候选生成工程：适合"每晚 1 小时"的六件事

1. **两段漏斗取代宽召回**：第一段全市场机械打分（价值/质量/低波/反转/PEAD），第二段才给 LLM。"稳健股票池 → 因子增强精选"就是 A 股已验证的两段式结构（[国信](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/11/rptid/786013348601/index.phtml)）。
2. **行业中性 + 每行业配额**：先行业内排序再跨行业取头部，避免候选被单一强势行业占满；组合层再加行业权重上限（国信用 15% 行业 / 3% 个股）。
3. **结构化候选卡片**：每只固定 12–15 行（价格位置、波动、换手、估值分位、行业排名、事件旗标、命中通道、一句话反方观点），关键字段置顶。**建议 30–50 张/晚，分 2 批**，不要 114 行长表。
4. **regime-aware 槽位**：按指数趋势 + 行业动量分散度 + 涨跌停家数判定进攻/中性/防守，直接改当日通道配额与持仓槽位。证据：动量因子在震荡市 ICIR +0.45、牛市 −0.36、熊市 −0.24；且高动量行业内动量/反转因子更有效、低动量行业内失效（[BigQuant](https://bigquant.com/wiki/doc/vmpoW4sE1e)、[申万](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/lastest/rptid/825501120248/index.phtml)）。
5. **观察名单 + 触发条件 + 事件日历**：财报披露日、解禁日、业绩预告是唯一"日期已知"的信息，应做成日历驱动的条件单式观察，而不是每晚重新全市场扫描。华泰明确指出 PEAD 类指标必须"动态跟踪个股实时披露情况"（[华泰](https://m.163.com/dy/article/KRGO6KRB05568W0A.html?spss=adap_pc)）。
6. **负面清单前置 + 跨日持续性打分**：财报前 N 日、解禁窗口、成交额占比/换手率极端分位、连续涨停、ST/科创/北交 → 在**生成阶段硬过滤**，不交给 LLM 判断；候选连续多日进池则加分、掉出则降权，用"持续性"对冲单日噪声。

## 四、常见陷阱

- **幸存者偏差**：只回测存续股票会系统性高估收益。上述动量研究纳入 324 只退市股（占 5.9%），样本从 5,163 只扩到 5,487 只（[BigQuant](https://bigquant.com/wiki/doc/vmpoW4sE1e)）。
- **前视偏差与训练污染**：LLM 训练语料覆盖回测期时会"记住"答案；匿名化公司名可部分缓解，但会引入"分心效应"（[Glasserman & Lin](https://arxiv.org/abs/2309.17322)）；严格按时间切分训练的 ChronoBERT/ChronoGPT 表明污染程度因模型与应用而异（[2502.21206](https://arxiv.org/abs/2502.21206)）。
- **过拟合**：动量研究扫了 8 组参数、牛/熊/震荡分组里"震荡"仅 15 期；PEAD 结论来自单一年报样本——这类结论只能当"方向性先验"，不能当参数。
- **长表注意力衰减**：见上文 Context Rot，114 行候选表已接近"读不完"。
- **用 LLM 做回测不可靠**：TradingAgents 声称 AAPL 同期买入持有 −5.23%、Agent +26.62%/Sharpe 8.21，第三方复算买入持有实为 **+9.12%**，且未计成本、仓库存在前视偏差 issue（[复现质疑](https://dev.to/trow126/the-most-starred-llm-trading-paper-claims-buy-and-hold-lost-523-it-actually-gained-912-1jj6)）。**结论：LLM 的收益类回测数字一律降级为"不可采信"，只采信其架构经验。**

## 五、对当前系统的 5 条可落地启示

（以下均为**我的建议**，依据上文证据外推，落地前需在模拟盘做 3 个月对照验证。）

1. **改召回目标函数，而不是加通道**：把"六路技术面"改成"四条正交打分轴"——反转/超跌（20 日）、低波低换手、估值质量、PEAD/业绩跳跃；动量只保留残差动量（行业+市值中性）一条。当前五条通道同向，等于人为把候选池压成"上涨子集"。
2. **候选池从 114 只压到 40–60 只，并改成行业中性配额**：每行业最多 3–4 只、强制覆盖 ≥8 个行业；同时候选按"每行业 Top-K"而非全局 Top-N 截断，避免行业抱团。
3. **给 LLM 的是卡片不是表格**：30–50 张固定字段卡片、分 2 批、关键指标置顶、每张卡附"反方一句话"；把"点评 6–8 只"改成"先淘汰到 12 只、再排序取 6 只"，减少单次判断跨度。
4. **加 regime 开关 + 观察名单**：用指数趋势/行业动量分散度决定当日是"进攻（动量+突破配额高）/中性/防守（低波+现金）"；把财报日、解禁日做成日历，触发才进池，替代每日全市场重扫。
5. **负面清单与组合约束硬编码**：财报前 5 日、解禁前后 10 日、换手率/成交额占比极端分位、连续涨停 → 生成阶段直接剔除；组合层约束改为"同行业 ≤2 只、风格去重、两两 60 日相关性 ≤0.7"，单股上限服从 2–6 只的集中度现实，不照抄机构 3% 的分散化参数。所有新规则先跑 3 个月模拟盘对照，不做参数寻优。

## 证据分级与局限

「有证据」= 可查的公开回测/制度文件；「合理推断」= 由多条证据外推、无直接检验；「我的建议」= 本文判断。局限：A 股因子证据多来自券商/平台回测，存在样本内选择与成本假设差异；LLM Agent 论文多为美股、短窗口、未计成本，**收益数字不可外推**，只有架构设计可借鉴。
