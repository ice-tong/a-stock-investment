> 本轮问题：**加入时点财务信息（盈利、估值、现金流）后，能否得到在留出集上也跑赢基准的方案？**

## 1. 沿用第一轮

股票池、资格、交易规则（月末信号、次日开盘、等权前 20、0.35%/来回、买不进留现金、跌停顺延）、ST 口径（当前名称）全部不变。

## 2. 新增：时点财务数据

- 来源：东方财富业绩报表 `ak.stock_yjbb_em(date=报告期)`，2018Q1 ~ 2026Q3，全市场。
- 字段：每股收益（年初至今累计）、净利润（年初至今累计）、每股经营现金流（年初至今累计）、每股净资产。
- **可用时点 = 法定截止日次日**：一季报 05-01、半年报 09-01、三季报 11-01、年报次年 05-01。不使用实际披露日，以完全避开前视；代价是信息平均滞后约 1 个月。
- **TTM**：TTM(本期) = 上年年报 + 本期累计 − 上年同期累计；年报期 TTM = 年报本身。缺任一项则该期 TTM 记为缺失。
- 估值：EP = TTM 每股收益 / 信号日成交均价（未复权，取当日成交额/成交量）。
- 已知局限：报表数值是接口当前返回值，可能包含后续追溯调整（轻度前视）；总股本变化会让 TTM 每股指标有小误差。

第一轮的 B 已用过。本轮按 `md5("r2:" + code)` 重新随机分成 **C（发现集）/ D（留出集）**。
局限：C/D 中的所有股票在第一轮都被小市值规则看过；本轮规则是新的，但含小市值成分的 G1、G2、G4 并非完全独立。

## 4. 假设（5 条，取排序最前 20 只）

| # | 规则 | 机制 |
|---|---|---|
| G1 盈利小市值 | 先要求 TTM 净利润 > 0，再取流通市值最小 | 小市值的雷与壳价值集中在亏损股；2024 年退市新规后壳价值下降，盈利的小票不是在押注壳 |
| G2 小市值+EP | 在 EP > 0 的股票中，流通市值升序排名与 EP 降序排名等权相加，取最优 | 小盘溢价与价值溢价合成（中国版三因子模型的两条腿） |
| G3 纯价值 | EP > 0 中 EP 最高 | 对照组：价值单独是否有效 |
| G4 质量小市值 | 要求 TTM 净利润 > 0 且 TTM 每股经营现金流 > 0，再取流通市值最小 | 在 G1 基础上排除「利润无现金」的财务风险 |
| G5 去壳价值 | 剔除流通市值最小 30% 后，EP > 0 中 EP 最高 | Liu–Stambaugh–Yuan（2019）：剔除壳污染后价值因子更干净 |

## 5. 门槛（全部满足才存档；比第一轮更严）

2. C 集三段（2020–22、2023–24、2025–26）年化均 > 0；

4. D 集扣费 CAGR ≥ 5%，且**全期相对等权基准超额 > 0**（新增，补第一轮的漏洞）；
5. 最大回撤 > 40% 的标红。
